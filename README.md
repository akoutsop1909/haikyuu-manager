# haikyuu-manager
A multipurpose Discord bot featuring automated Japanese-to-English Twitter/X translation alongside a volleyball RPG game.

## 💻 Tech Stack
* **Discord API (`discord.py`)**: Powers the bot client, slash/UI interactions, and real-time channel event monitoring.
* **Google Gemini API**: Handles automated text translation and multimodal image OCR for Japanese Twitter/X posts.
* **PostgreSQL (`asyncpg`)**: Manages persistent user inventories, card stats, and team lineups asynchronously.
